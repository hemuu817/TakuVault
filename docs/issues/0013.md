## Body

## 目的
Where used の前提となる「セッション」と「シーン（default_scene常設）」を整備し、Usageの参照整合性を崩さないCRUDを提供する。

---

## DoD（完了条件）
### Session
- [ ] Session CRUDが動作（MVPは Cocofolia 固定）
- [ ] room_url は **http/https のみ許可**（サーバ側バリデーション）
- [ ] room_url のリンク表示は **`target="_blank"` + `rel="noopener noreferrer"`** を必ず付与
- [ ] 認可（所有権）を前提に CRUD が隔離される（URL直打ち対策含む）

### Scene（default_scene常設）
- [ ] Scene CRUDが動作し、**各Sessionに default_scene が常に1つ存在**する
- [ ] default_scene は **position=1 を占有**し、ユーザー作成Sceneは **position=2 から採番**
- [ ] default_scene は削除不可（UI非表示だけでなく、URL直打ちでも不可）
- [ ] scenes.position は session 内で一意（衝突時の再計算/リトライ方針を固定）
  - [ ] 採番：`max(position) + 1`
  - [ ] 衝突時：再計算してリトライ（例：unique_violation を捕捉して再試行）

### DB整合性（後続Usageの前提を崩さない）
- [ ] scenes: `NOT NULL` / `FK` / `UNIQUE` が migration で実装済み
  - [ ] `session_id NOT NULL`（FK：Sessions）
  - [ ] `position NOT NULL`
  - [ ] `UNIQUE(session_id, position)`（default_scene一意を position=1 で担保）
  - [ ] `UNIQUE(session_id, id)`（usagesの複合FK成立用）
- [ ] usages 側で必要となる複合FKの前提が揃っている（実装はEpic D）
  - [ ] `usages(session_id, scene_id) -> scenes(session_id, id)` が成立できる状態

---

## スコープ
### 含む
- Session: Cocofolia固定、room_url保存（同期/API連携なし）
- Scene: default_scene 自動生成（position=1固定）、position管理、削除ポリシー
- 認可（所有権）を前提にしたCRUD（policy_scope/authorize）
- 参照整合性のための DB 制約・index（Scenes側の整備）

### 含まない
- 複数ツール対応（Udonarium等）
- room_urlのホストallowlist（MVPでは不採用）

---

## 受け入れ条件（Yes/No）
### Session
- [ ] Sessionを作成/更新/削除できる（所有権で隔離）
- [ ] room_url が不正スキーム（ftp/javascript/data等）の場合は保存できない
- [ ] room_url は表示時に安全なリンク属性が付与される（noopener/noreferrer）

### default_scene 常設
- [ ] Session作成直後に **default_scene（position=1）が必ず生成**される
  - [ ] default_scene生成に失敗した場合、Session作成も失敗する（transactionで原子性）
- [ ] 各Sessionに position=1 のSceneが必ず1つ存在する
- [ ] position=1 のSceneは削除できない（URL直打ちでも不可）

### position 一意 + 採番
- [ ] Sceneのpositionが重複しない（DB制約で保証）
- [ ] Scene追加時、positionは `max+1` で採番される
- [ ] position衝突が起きても再計算/リトライで解決できる（方針が固定されている）

### 削除ポリシー（C側の責務範囲）
- [ ] Session削除時：配下Sceneは削除される（Usage削除はEpic D側で整合させる）
- [ ] default以外のScene削除は可能（Usage削除はEpic D側で整合させる）

---

## 実装方針（固定）
- default_scene は `is_default` 等のフラグで管理せず、**position=1 を default と定義**する
- default_scene 生成は **Session作成と同一transaction内**で行う
- default_scene 削除禁止は **Controller + Policy + Model** で三重に防御する（UI非表示だけでは不可）

---

## 最小テスト/検証
### Model / DB
- [ ] Model：room_url バリデーション（http/httpsのみ）
- [ ] DB：`UNIQUE(session_id, position)` が効く（同一session内でposition重複不可）
- [ ] DB：`position` / `session_id` がNOT NULL
- [ ] default_scene（position=1）生成が transaction で保証される

### Policy
- [ ] Policy：他人のSession/Sceneにアクセス不可（一覧/詳細/更新/削除）

### System
- [ ] Session作成 → default_scene（position=1）生成確認
- [ ] Scene追加 → positionが 2,3,... と採番される
- [ ] Scene並び（position順）確認
- [ ] default_scene（position=1）削除をURL直打ちしても失敗することを確認
