# MVP: パスワードリセットのメール送信設定（Devise Recoverable / dev + test + prod 最小構成）

## 目的（このIssueで達成する価値）
Deviseのパスワードリセット（recoverable）が「開発環境で確認できる」「テストで再現性を持って検証できる」「本番環境で実際に送信できる」状態を最小構成で成立させる。

---

## スコープ（やること）
### 1) Devise Recoverable の有効化（前提確認）
- Userモデルの devise に `:recoverable` が入っていること
- recoverable用カラムがDBに存在すること（migration済み）
- Deviseのパスワード再設定導線（`/users/password/new`）が有効であること

### 2) 開発環境（development）：letter_opener_web でメールをブラウザ確認
- `letter_opener_web` を導入
- ActionMailer を `:letter_opener_web` に設定
- DeviseのURL生成に必要な `default_url_options`（host/port）を設定
- `/letter_opener` にアクセスできる

### 3) テスト環境（test）：`:test` delivery で再現性のある検証
- `letter_opener_web` は development 専用。test では `delivery_method = :test` を使う
- `ActionMailer::Base.deliveries` を用いて「送信されたこと」「本文にトークンが含まれること」を検証できる

### 4) 本番環境（production / Render）：SMTPでメール送信
- ActionMailer を `:smtp` に設定
- SMTP接続情報を環境変数で管理（RenderのEnvironmentで設定）
- DeviseのURL生成（`default_url_options`）を本番ホストに設定（HTTPS）

### 5) 送信元（From）の固定
- `MAILER_FROM` を環境変数で用意し、Deviseの `mailer_sender` に反映する
- SMTPプロバイダによっては From が未設定だと拒否されるため必須とする

---

## 非スコープ（やらない）
- Confirmable（メール確認）/ Lockable（ロック）
- 2FA（多要素認証）
- メール文面の大幅カスタム（ブランド対応等）
- 高度な配信分析（Webhook/イベントログ）
- Direct Upload / 進捗表示（%）などアップロード高度化

---

## 実装手順（最小）

### A. 開発環境：letter_opener_web
#### 1) Gem追加
- `Gemfile`（developmentのみ）
  - `gem 'letter_opener_web', group: :development`

#### 2) ルーティング追加
- `config/routes.rb` に mount
  - `mount LetterOpenerWeb::Engine, at: "/letter_opener" if Rails.env.development?`

#### 3) ActionMailer設定（development）
- `config/environments/development.rb`
  - delivery_method を `:letter_opener_web`
  - default_url_options を設定（例：localhost:3000）

（例）
```ruby
# config/environments/development.rb
Rails.application.configure do
  config.action_mailer.perform_deliveries = true
  config.action_mailer.raise_delivery_errors = true
  config.action_mailer.delivery_method = :letter_opener_web
  config.action_mailer.default_url_options = { host: "localhost", port: 3000 }
end
