# Brakeman EOLRails警告を期限付きで抑制

## 背景

GitHub Actions の `scan_ruby`（`bin/brakeman --no-pager`）で、Rails 7.2.3 に対する `EOLRails` 警告が出てCIが失敗している。

```text
Category: Unmaintained Dependency
Check: EOLRails
Message: Support for Rails 7.2.3 ends on 2026-08-09
File: Gemfile.lock
````

Rails 7.2.x は 2026-08-09 までセキュリティサポート対象であり、現時点では完全EOLではない。

しかし、Brakeman がサポート期限接近を `Unmaintained Dependency` として検知するため、今回のTailwind retrofit PRとは無関係にCIが失敗している。

このIssueでは、Rails 8移行を行わず、`EOLRails` 警告のみを期限付きで抑制してCIを復旧する。

恒久対応は別Issueの Rails 8移行で扱う。

## 目的

* Tailwind retrofit PRにRails 8移行を混ぜない
* CIを一時的にgreenへ戻す
* `EOLRails` の抑制理由と期限を明文化する
* Rails 8移行までの暫定対応であることを明確にする

## 対応方針

* `EOLRails` 警告のみを `config/brakeman.ignore` に追加する
* `config/brakeman.ignore` の `note` に、以下を明記する

  * Rails 7.2.x は 2026-08-09 までセキュリティサポート対象であること
  * このignoreは恒久対応ではないこと
  * Rails 8移行Issueで恒久対応すること
  * 期限は 2026-08-09 までとすること
* 他のBrakeman警告は抑制しない
* Rails / Ruby / Gemfile.lock の更新はこのIssueでは行わない

## `note` に書く内容の方針

`config/brakeman.ignore` の対象warningには、以下の趣旨を必ず書く。

```
Rails 7.2.x is security-supported until 2026-08-09, but Brakeman flags EOLRails before the support end date.
This ignore is temporary and only for restoring CI while keeping the Tailwind retrofit PR separated from the Rails 8 migration.
Permanent fix: upgrade to Rails 8 in a separate issue before 2026-08-09.
```

## 注意

これは恒久対応ではない。

Rails 7.2.x のセキュリティサポート終了日は 2026-08-09 であるため、それまでにRails 8移行Issueで恒久対応する。

このIssueでは、CI復旧を目的として `EOLRails` 警告のみを期限付きで抑制する。

Rails 8移行、Ruby更新、ADR-0012改訂、Render/Worker構成変更は別Issueで扱う。
