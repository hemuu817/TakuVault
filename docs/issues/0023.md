# Issue #23: (18) 素材一覧とセッション一覧の統合

## Body

素材一覧とSession管理の統合

目的

現在別画面となっている素材一覧とセッション一覧を統合し、素材一覧を主画面として、同一画面内からSessionの選択・管理と使用素材の確認を行えるようにする。

独立したセッション一覧との往復をなくし、Asset・Session・Scene・Usageの関係を一つの画面から確認できる状態を成立させる。

実装着手条件

* ADR-00XX（ADR-0010の後継ADR）がAcceptedになっている
* ADR-0010がSupersededとなり、ADR-00XXへの参照が追加されている
* 本IssueがADR-00XXを参照し、旧仕様の重複記載が除去されている

スコープ

含む

* 素材一覧を主画面とした統合画面
* 統合画面内でのSession選択
* Session切替時の非同期表示更新
* Session / Scene / Usageの表示
* Scene配下Usageの遅延ロード
* Sessionの作成・編集・削除への導線
* Sceneの作成・編集・削除への導線
* Session / Sceneの作成・編集・削除結果の統合画面への反映
* 独立したセッション一覧を通常導線から廃止
* Assetタイルから既存Asset詳細への直接導線
* 所有権認可とfail-closed
* 空状態・通信失敗時の表示
* 関連するrequest spec / system spec
* 統合画面および遅延ロード時のN+1防止

含まない

* Asset詳細のモーダル化
* role / kind / Sessionによる絞り込み
* Asset検索
* タグ機能
* 未整理（Usage0）一括割当画面の再設計
* Session詳細「セッション素材一覧」の廃止・再設計
* ドラッグ&ドロップ
* ZIPダウンロード
* 変換処理
* AI分類
* 高度なキャッシュ戦略
* Session / Scene / Usage / AssetのDB構造変更

仕様

統合画面固有の仕様

以下は、ADR-00XX（ADR-0010の後継ADR）を正本とする。

* 画面構造
* 統合画面の配置先
* Session未選択時の表示
* Session切替時の状態遷移
* URL
* 非同期更新方式
* 遅延ロード契約
* 空状態と通信失敗時の表示
* CRUD後の遷移および選択状態
* 既存Session画面の扱い
* 統合画面固有の取得境界と認可適用箇所
* 表示順

本Issueでは、ADR-00XXに従って統合画面を実装する。

既存仕様の正本

* default_sceneの定義と不変条件はADR-0001に従う
* Usageの割当・重複・所有権混在時の扱いはADR-0006に従う
* 所有権の正本とpolicy_scope起点のfail-closedはADR-0007に従う
* Usage.roleの表示順はADR-0016に従う
* Session詳細「セッション素材一覧」は既存仕様を維持する

受け入れ条件

統合画面

* 素材一覧を主画面としてAssetを確認できる
* 統合画面内でSessionを選択できる
* Session切替時にページ全体を遷移せず対象表示が更新される
* Sessionを連続して切り替えた場合、最終的に選択したSession以外の応答で表示が上書きされない
* 選択したSessionのScene / Usageを確認できる
* Scene配下のUsageが必要なタイミングで遅延ロードされる
* Assetタイルから編集画面を経由せずAsset詳細へ遷移できる
* 独立したセッション一覧への通常導線が残っていない

空状態

* Sessionが存在しない場合でも画面が破綻しない
* Session未選択時にADR-00XXで定めた状態が表示される
* SceneまたはUsageが存在しない場合でも、ADR-00XXで定めた空状態が表示される
* Usageが0件のSceneを遅延ロードした場合、エラーではなく空状態が表示される

Session / Scene管理

* 統合画面からSessionの作成・編集・削除へ到達できる
* Session作成後、作成したSessionを統合画面から選択できる
* Session編集後、変更内容が統合画面に反映される
* Session削除後、削除済みSessionおよび配下データが表示に残らない
* 統合画面からSceneの作成・編集・削除へ到達できる
* Scene作成後、対象Session配下に作成したSceneが表示される
* Scene編集後、変更内容と表示順が統合画面に反映される
* Scene削除後、削除済みSceneおよび配下Usageが表示に残らない
* 選択中Sessionが削除された場合、削除済みSessionを参照し続けない

認可

* 他ユーザーのSession / Scene / Usage / Assetが表示されない
* 他ユーザーのSessionまたはSceneを指定したURLは404相当となる
* SessionとSceneの親子関係が不一致の場合は404相当となる
* 認可されていないAssetのURLまたはプレビューURLを生成しない

回帰

* default_sceneの作成・position=1固定・削除不可が維持されている
* 既存のAsset CRUDが利用できる
* 既存のSession / Scene CRUDが利用できる
* 既存のUsage作成・削除が利用できる
* 未整理（Usage0）一括割当が利用できる
* Asset詳細Where usedが利用できる
* Session詳細「セッション素材一覧」が利用できる

DoD

* ADR-00XXがAcceptedになっている
* ADR-0010がSupersededとなり、ADR-00XXを参照している
* 本IssueがADR-00XXを参照している
* 統合画面の主要導線をrequest spec / system specで検証している
* 所有権境界をrequest specで検証している
* 空状態をrequest specまたはsystem specで検証している
* Session / Scene CRUD後の表示反映を検証している
* Session / Scene / Usage / Asset / Active Storage参照で不要なN+1が発生していない
* 関連する既存specが成功している
* 手動QAでSession切替、連続切替、Scene / Usage表示、CRUD導線、Asset詳細遷移を確認している
* 本Issueの非スコープ機能を実装していない

失敗ケース

* Sessionを連続して切り替えた際、古い非同期応答によって表示が上書きされる
* Session切替後も直前のSessionのScene / Usageが表示に残る
* 他ユーザーのSession / Scene / Usage / Assetを取得できる
* SessionとSceneの親子関係が不一致でも取得できる
* Usageが0件のSceneを展開するとエラーになる
* Session / Scene削除後も遅延ロード済みの表示が残る
* Session / Scene作成・編集後も統合画面に古い情報が表示される
* Scene展開ごとにUsage / Asset / Active StorageへのN+1が発生する
* ブラウザバックまたはTurboキャッシュ復元後、選択Sessionと表示内容が食い違う

最小テスト / 検証

Request

* 自分のSessionを対象とする表示更新が成功する
* 他ユーザーのSession指定が404相当となる
* 自分のSession配下のScene / Usage遅延ロードが成功する
* 他ユーザーのScene指定が404相当となる
* SessionとSceneの親子関係が不一致の場合は404相当となる
* Usageが0件の場合も空状態として成功レスポンスを返す
* レスポンスに他ユーザーのUsage / Assetが含まれない
* Session / Scene削除後に削除済みデータを取得できない

System

* 統合画面内でSessionを選択できる
* Session切替時にページ全体が遷移しない
* Session切替後、対象SessionのSceneだけが表示される
* Scene展開時にUsageが遅延ロードされる
* Sessionを連続して切り替えても最終選択と表示内容が一致する
* Session / Scene作成・編集・削除後に統合画面へ結果が反映される
* AssetタイルからAsset詳細へ直接遷移できる
* 独立したセッション一覧への通常導線が表示されない
* Session / Scene / Usageが存在しない場合でも空状態が表示される

回帰

* Asset CRUD
* Session / Scene CRUD
* Usage作成・削除
* 未整理（Usage0）一括割当
* Asset詳細Where used
* Session詳細「セッション素材一覧」
* default_sceneの不変条件
* 所有権認可
