## Body

(18) 素材一覧とSession管理の統合

目的

現在別画面となっている素材一覧とSession管理を統合し、素材一覧を主画面として、同一画面内からSessionの選択・管理と使用素材の確認を行えるようにする。

独立したSession一覧との往復をなくし、Asset・Session・Scene・Usageの関係を一つの画面から確認できる状態を成立させる。

統合画面の配置、選択中Sessionの扱い、ブラウザ履歴、非同期更新、Scene配下Usageの遅延ロード、CRUD後の表示状態、認可および取得境界はADR-0018を正本とする。

スコープ / 実装対象

統合画面

* 素材一覧を主画面として、Session管理領域を同一画面に統合する
* Asset一覧はSessionの選択有無にかかわらず表示する
* Session切替時はAsset一覧を維持し、Sessionに依存する領域だけを更新する
* Session未選択状態、Sessionが0件の状態、通信失敗状態を表示できるようにする

Session選択

* URLのsession_idに基づいて選択中Sessionを表示する
* session_idがない場合はSession未選択状態とする
* Sessionが存在していても、先頭Sessionを自動選択しない
* 統合画面内でSessionを切り替えた場合は、ADR-0018に従ってURLとブラウザ履歴を更新する
* Session切替要求が競合した場合は、最後に選択したSessionの結果だけを表示する
* リロードおよびTurboキャッシュ復元後は、URLから選択状態を再構築する

Session選択UIの具体形式は、このIssueでは固定しない。

SceneとUsageの表示

* Session選択後、選択Sessionに属するSceneを、Usage未取得の状態でも一覧表示する
* Scene配下Usageは、対象Sceneの表示が必要になった時点でScene単位に取得する
* 初期表示時に、全Session配下のScene・Usage・Assetを一括取得しない
* Usageが0件の場合は、エラーではなく空状態を表示する
* Scene配下Usageに表示されたAssetから、既存のAsset詳細へ直接遷移できるようにする

Session / Scene管理

* 統合画面から既存のSession作成・編集・削除へ移動できるようにする
* 統合画面から既存のScene作成・編集・削除へ移動できるようにする
* CRUD完了後は、ADR-0018で定められたSession選択状態へ戻す
* 削除済みのSession、Sceneおよび遅延ロード済みUsageを画面に残さない

既存導線

* 独立したSession一覧を通常の主要導線として残さない
* /sessionsへのアクセスでは独立した一覧を表示せず、session_idのない統合画面へredirectする
* Session詳細「セッション素材一覧」は既存画面として維持する

通信失敗

* Session領域またはScene配下Usageの取得に失敗した場合は、対象領域にエラー状態を表示する
* 取得に失敗した領域に古いSession・Scene・Usageを表示し続けない
* 通信失敗時もAsset一覧は維持する
* 失敗した領域を再取得できる導線を表示する

受け入れ条件

統合画面とSession選択

* Sessionが0件でもAsset一覧を利用できる
* session_idがない場合はSession未選択状態になる
* Sessionが存在していても先頭Sessionが自動選択されない
* 自分が所有する有効なSessionを選択すると、対象Sessionに属するSceneが表示される
* Session切替時もAsset一覧領域が維持され、Session依存領域だけが更新される
* 存在しない、削除済み、または他ユーザーのSessionを指定した場合は404相当になる
* 連続してSessionを切り替えた場合、最後に選択したSessionだけが表示される
* リロードおよびTurboキャッシュ復元後も、URLと選択中Sessionが一致する
* 統合画面内でSessionを切り替えても、Session選択ごとの履歴が追加されない
* ブラウザバックで、統合画面へ来る前の画面へ戻れる

SceneとUsage

* 選択中Sessionに属するSceneだけが表示される
* Usage未取得の状態でも、選択中SessionのScene一覧が表示される
* Scene配下UsageがScene単位で遅延表示される
* 初期表示で全Session配下のScene・Usage・Assetを一括取得しない
* Usageが0件のSceneでは、正常な空状態が表示される
* 同一Assetに複数のUsageがある場合、各Usageが個別に表示される
* 選択中Sessionに属さないSceneのUsage取得要求は404相当になる
* Usageに表示されたAssetから、編集画面を経由せずAsset詳細へ遷移できる

CRUD後の状態

* Session作成後は、作成したSessionが選択された統合画面へ遷移する
* Session編集後は、対象Sessionの選択状態が維持される
* 選択中Sessionの削除後はSession未選択状態になり、別Sessionを自動選択しない
* 選択中Sessionの削除後は、削除対象のScene・Usageが画面に残らない
* Scene作成・編集・削除後も、親Sessionの選択状態が維持される
* Scene作成・編集・削除の結果が統合画面へ反映される
* 削除済みSceneおよびその配下Usageが画面に残らない

既存導線・通信失敗・認可

* /sessionsへアクセスすると、session_idのない統合画面へredirectする
* 独立したSession一覧への通常の主要導線が残っていない
* Session詳細「セッション素材一覧」が従来どおり利用できる
* 通信失敗時に、対象領域へエラー状態と再取得導線が表示される
* 通信失敗時に、古いSession・Scene・Usageを表示し続けない
* 通信失敗時もAsset一覧が維持される
* 他ユーザーのSession・Scene・Usage・Assetが表示または参照されない
* 単一SceneのUsage取得時に、Usage・Asset・Active Storage関連の件数ごとに追加SQLが発生しない

テスト観点

Request spec

* session_idなしで統合画面を表示できること
* 自分が所有する有効なsession_idで対象Sessionを表示できること
* 存在しない、削除済み、または他ユーザーのsession_idを404相当で拒否すること
* /sessionsからsession_idのない統合画面へredirectすること
* 選択Sessionに属さないSceneの取得要求を404相当で拒否すること
* Scene配下Usageを取得できること
* Usageが0件の場合に空状態HTMLを200で返すこと
* 同一Assetの複数Usageを重複排除しないこと
* 他ユーザーのUsageまたはAssetを応答へ含めないこと
* Session / Scene CRUD後の遷移先と選択状態がADR-0018に一致すること

JavaScript対応system spec

* Session未選択状態からSessionを選択できること
* Session切替時にAsset一覧を維持したままSession依存領域だけが更新されること
* 連続切替時に最後の選択結果だけが表示されること
* Sceneの表示に応じてUsageが遅延ロードされること
* Session切替時のURL更新とブラウザバックがADR-0018に一致すること
* リロードおよびTurboキャッシュ復元後に選択状態が再構築されること
* Session / Scene CRUD後に正しい選択状態へ戻ること
* UsageのAssetタイルからAsset詳細へ直接遷移できること

通信失敗時のエラー表示および再取得動作は、JavaScript対応system specまたは同等の自動テストで確認する。

性能・回帰確認

* Scene配下Usage取得時に、Usage・Asset・Active Storage関連の件数ごとにSQLクエリが増加しないこと
* 既存のAsset一覧、Asset詳細、Session CRUD、Scene CRUDおよびUsage表示に関するspecが成功すること
* Session詳細「セッション素材一覧」の表示とAsset詳細への遷移が壊れていないこと
* Issue #163で実装済みの素材一覧上のkind連動UIが壊れていないこと

Out of Scope

* Session詳細「セッション素材一覧」の廃止または再設計
* Session / Scene CRUDフォームおよびAsset詳細のモーダル化・インライン化
* Session選択UIの最終形式と、将来のSession件数増加に対応する最終UI設計
* Scene展開状態の永続保存
* 素材一覧の検索・絞り込み・ソート機能
* Issue #163で実装済みのkind連動UIの仕様変更
