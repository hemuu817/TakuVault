## Body

## 目的（このIssueで達成する価値）
Where used（Session/Scene/Role）を保ったまま、素材（Usage）を単一画面で参照・切替できる状態を成立させる（ツリー骨格＋遅延ロード基盤）。

## 仕様（このIssueで実装する要件）
### 1) 表示の主語
- ツリーの葉は **Usage（asset + session + scene + role）** とする
- 同一Assetの使い回しによる **Usageの重複表示は許容**する
- 表示は role 見出しで分類して出す（「同じassetを使用している」ことが分かる表示を行う）

### 2) 状態遷移（サイドバー切替）
- サイドバーで Session を切替えたら **Sceneは未選択に戻す**（sceneスコープを外す）
- Session/Scene の切替は **スコープ選択**として扱う（フィルタ扱いにしない）

### 3) パフォーマンス（入れ子ツリーの重さ）
- 一覧は **折りたたみ + 遅延ロード**で実装する
- ツリー骨格（Session/Scene）は先に描画し、Scene展開時に中身（Usage/素材）を読み込む
- 遅延ロード契約（入力/出力/認可/空状態/再取得）は **ADR-0007** を正本とする

### 4) クエリ方針（安全側）
- 取得起点は必ず policy_scope に固定する
- N+1回避のため includes を使用する（必要な範囲）
- 表示順
  - Scene：position順
  - role：固定順（enum順等、一定の順序）
- ※葉がUsageなので、**重複排除（distinct）は基本しない**

### 5) “未整理（Usage0）”の居場所（通知のみ）
- Session/Scene削除等で配下の素材が見えなくなる場合は **ポップアップで通知**
- ポップアップには **未整理フォルダ（Usage0）への導線（リンク）**を付ける
- 文言は「移動」ではなく「割当（Where used）が解除され、未整理に表示される」ニュアンスに寄せる

### 6) 削除後の表示整合（通知のみ）
- Session/Scene削除後、配下の素材は表示上消える（= Usageが消える/見えなくなる）
- 誤認防止として、ポップアップ通知＋未整理へのリンクでフォローする
- Scene削除は統合/移動ではなく **配下Usage削除**で整合させる（既決）

### 7) 認可境界（二層で固定）
- 全取得は必ず policy_scope 起点（スコープ外は404寄せ）
- ネスト資源は **親で絞ってから子を探す**（session→scene→usages）
- 遅延ロードの認可・取得手順・fail-closedは **ADR-0007** に従う

## スコープ
**含む**
- 統合画面（Session/Scene骨格の描画）
- Usage（葉）表示（role見出しで分類、重複表示許容）
- Session切替時にScene未選択へリセット
- Scene展開時の遅延ロード（Usage取得）
- 区切り線等でセッション境界の視覚化
- Session/Scene削除後のポップアップ通知＋未整理導線
- 認可（二層）と fail-closed の担保（ADR-0007準拠）

**含まない**
- role/kind等の絞り込み挙動（role変更時の再取得・空ノード保持ルール含む）は #29 で扱う
- Asset検索（q）/ タグ絞り込み
- 未整理画面そのものの実装（別Issue）
- 高度なパフォーマンス最適化（キャッシュ戦略等）

## 受け入れ条件（Yes/No）
- [ ] 葉がUsageとして表示され、同一AssetのUsage重複が許容されている
- [ ] role見出しで分類表示され、「同じassetを使用している」ことが分かる
- [ ] Session切替でSceneが未選択に戻る
- [ ] ツリーは折りたたみ+遅延ロードで動作し、Scene展開で素材が読み込まれる
- [ ] Sceneはposition順、role表示は固定順で表示される
- [ ] Session/Scene削除後、「割当解除→未整理に表示」ニュアンスのポップアップ＋未整理リンクが出る
- [ ] policy_scope起点＋ネスト探索で、他ユーザーのデータは表示されない（漏れない）

## DoD（完了条件）
- [ ] 遅延ロードのRequest spec（200/404）を用意している（詳細はADR-0007準拠）
- [ ] policy_scope を全取得に適用し、親→子の探索順が統一されている（ADR-0007準拠）
- [ ] 手動QAで折りたたみ/遅延ロード/切替/ポップアップ文言を確認済み

## 失敗ケース（最低3つ）
- [ ] Session切替でSceneスコープが残り、表示が破綻する
- [ ] 遅延ロードで認可漏れが起き、他ユーザーのUsageが取得できてしまう
- [ ] Scene展開時にN+1が発生し、一覧が極端に遅くなる

## 最小テスト/検証
**Policy**
- [ ] policy_scope(Session/Scene/Usage) で所有権が守られる

**Request（遅延ロード）**
- [ ] 自分の session+scene の遅延ロードが 200
- [ ] 他人の session/scene の遅延ロードが 404（または403、全体方針に従う）

**System**
- [ ] Session切替でScene未選択に戻る
- [ ] Scene展開で遅延ロードが動作する
