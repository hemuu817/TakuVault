## Body

## 目的（このIssueで達成する価値）
#23 の統合画面（Where usedツリー）に対して、絞り込み（kind/role）と状態遷移（role変更時の再取得、空ノード保持）を追加し、参照・切替・絞り込みを単一画面で破綻なく成立させる。

## 仕様（このIssueで実装する要件）
### 1) フィルタ/スコープの意味（固定）
- Session/Scene は **切替（スコープ選択）**（= フィルタではない）
- フィルタは **kind / role** を対象とする
- Asset検索（q等）やタグ絞り込みは **この画面では扱わない（前提外）**

### 2) roleフィルタ（MVP最小・安全）
- roleは **フィルタとして扱う**
- Session/Scene切替でrole選択状態は維持される（roleは切替と独立）
- roleでヒットしない Session/Scene は **空ノードとして残す（非表示にしない）**
- role変更時、**展開済みSceneは再取得**する（MVPはこれが最小で安全）
  - 具体的な遅延ロード契約（入力/出力/空状態/再取得）は **ADR-0007** に従う
  - 未展開のSceneは、展開されたタイミングでその時点のrole条件で取得される

### 3) kindフィルタ（MVP方針：適用レイヤ固定）
- kindは **asset.kind** による絞り込み
- MVPでは **遅延ロード入力にkindを含めず**、取得後（表示側）でkindを絞り込む
- kindを遅延ロード入力に追加する場合は契約変更となるため、別Issue/ADRで扱う

### 4) 空ノード保持の範囲（固定）
- Session/Sceneは常に表示（空でも残す）
- kind/roleいずれの絞り込みでも、Session/Sceneは非表示にしない（空ノード保持）
- Role見出しを空でも出すかはMVPでどちらでもよいが、どちらかに固定する（#23/#29で同一）

### 5) クエリ/認可（#23方式 + ADR-0007に追従）
- 取得起点は必ず policy_scope
- ネスト資源は親で絞ってから子を探す（session→scene→usages）
- 遅延ロードの認可・取得手順・fail-closed・異常系は **ADR-0007** に従う

## スコープ
**含む**
- roleフィルタUIと挙動（展開済みSceneの再取得、role独立）
- kindフィルタUIと挙動（MVPは表示側フィルタ）
- フィルタ適用時も Session/Scene を空ノードとして保持（Where used構造を崩さない）
- 最小テスト（System / Request）追加（必要最低限）

**含まない**
- Asset検索（q）/ タグ絞り込み
- 高度な最適化（キャッシュ、サーバ側kind絞り込み等）

## 受け入れ条件（Yes/No）
- [ ] roleフィルタが動作し、ヒットしないSession/Sceneが空ノードとして残る
- [ ] Session/Scene切替でrole選択状態が維持される（roleは切替と独立）
- [ ] role変更時、展開済みSceneが再取得される（MVP最小・安全、詳細はADR-0007準拠）
- [ ] kindフィルタが動作する（MVPは表示側フィルタ）
- [ ] kind/roleいずれの絞り込みでもSession/Sceneが非表示にならない（空ノード保持）
- [ ] フィルタ適用中でもSession切替/Scene切替の意味が破綻しない（スコープ選択のまま）
- [ ] policy_scope前提で、他ユーザーのデータは表示されない（漏れない、詳細はADR-0007準拠）

## DoD（完了条件）
- [ ] 手動QAで role変更→展開済みScene再取得 を確認済み
- [ ] 手動QAで kindフィルタ適用→空ノード保持（Session/Scene）を確認済み
- [ ] role/kind/切替の同時操作など複合挙動は手動QAとし、System specは最小限に留める
- [ ] 最小テストを追加している（下記）

## 失敗ケース（最低3つ）
- [ ] roleフィルタで空ノードが消えてしまい、Where used の構造が崩れる
- [ ] role変更時に再取得されず、展開済みSceneの表示が古いままになる
- [ ] kindフィルタでUsage/assetの整合が崩れ、表示が破綻する（またはN+1悪化）

## 最小テスト/検証
**Request（遅延ロード：ADR-0007準拠）**
- [ ] 自分の session+scene の遅延ロードが 200
- [ ] 他人の session/scene の遅延ロードが 404（または403、全体方針に従う）
- [ ] roleパラメータ有りでも 200/404 が維持される
- [ ] role許容値外で 400

**System**
- [ ] roleフィルタ切替が機能し、展開済みSceneが再取得される
- [ ] kindフィルタ切替が機能する（表示側フィルタ）
- [ ] role/kind適用中でもSession/Sceneが空ノードとして残る
