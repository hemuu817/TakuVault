# Issue #30: (23) 未整理の素材ビュー

## Body

## 目的（このIssueで達成する価値）
Where used（Usage）が未割当の素材（Usage=0）を「未整理」として一箇所に集約し、削除や割当解除後でも素材が行方不明にならない状態を作る。

## 仕様（未整理の定義）
- 未整理＝ **Assetが usages を1件も持たない状態（Usage=0）**
- 判定は left join 等で「usages.id が NULL」を用いる（実装はscope/Queryに集約）

## スコープ
**含む**
- 未整理ビュー（例：/assets/unassigned または /assets?state=unassigned）
  - 表示対象：**policy_scope(Asset) のうち Usage を1件も持たない素材**
  - 一覧は `created_at desc` で固定表示
  - MVPは最大100件に制限する（将来ページング検討）
- 一覧表示項目（MVP最小）
  - サムネイル（画像）/ 音声は固定アイコン（再生しない）/ その他は汎用
  - display_name（未設定なら filename相当）
  - kind（表示のみ。絞り込みはしない）
  - 作成日時
- 導線
  - Asset詳細へ遷移できる
  - サイドバー（またはヘッダー）に「未整理」固定リンクを設ける
  - Session/Scene削除等のポップアップ通知から未整理へ遷移できる（関連Issue側で実装）
- 認可（固定）
  - policy_scope(Asset) 起点
  - 未整理判定で usages を参照するが、他ユーザーのUsage混入が起きないようにする（fail-closed）
- ActiveStorage/性能
  - includes(file_attachment: :blob) を用いN+1を回避する
  - 表示/ダウンロード/プレビューURLは必ず認可済みAsset経由で生成する（blob直露出はしない）
- 仕様の明確化
  - 「未整理＝Usageが0件」の定義を画面上にも明示する（ヘルプ文言）

**含まない**
- 未整理での一括割当（別Issue or ADR-0006 に基づき別タスク）
- 変換・プレビューの高度化（音声自動再生等）
- kind/role/session 等の絞り込みUI（MVP外）
- ドラッグ&ドロップでの割当（MVP外）

## 受け入れ条件（Yes/No）
- [ ] 未整理ビューに、自分の未整理素材（Usage=0）が表示される
- [ ] Usageを1件以上持つ素材は未整理ビューに表示されない
- [ ] 他ユーザーの素材は表示されない（policy_scope 起点）
- [ ] 一覧の順序が固定されている（created_at desc）
- [ ] 一覧は最大100件に制限される（MVP固定）
- [ ] Asset詳細へ遷移できる
- [ ] サイドバー（またはヘッダー）から未整理へ遷移できる
- [ ] 「未整理＝Usageが0件」の説明が画面上にある

## DoD（完了条件）
- [ ] 未整理判定のクエリが1箇所に集約されている（scope/Query Object）
- [ ] includes(file_attachment: :blob) 等でN+1が抑止されている
- [ ] System spec で「未整理のみ表示」「認可」「順序固定」「上限100件」「導線」を担保する
- [ ] 手動QAで、Session/Scene削除等により Usage=0 になった素材が未整理へ現れることを確認する

## 失敗ケース（最低3つ）
- [ ] Usageを持つ素材が未整理に混入する（判定ミス）
- [ ] 他ユーザーの素材が表示される（policy_scope漏れ）
- [ ] N+1 で極端に重くなる（includes不足）

## 最小テスト/検証
**Model/DB**
- [ ] 未整理判定（Usage=0）scope/Query が正しく動く
- [ ] created_at desc の順序が固定される
- [ ] 一覧が最大100件に制限される（MVP固定）

**Policy**
- [ ] policy_scope(Asset) 起点で他人の素材が出ない

**System**
- [ ] 未整理素材が表示される
- [ ] Usageあり素材は表示されない
- [ ] Asset詳細へ遷移できる
- [ ] サイドバー（またはヘッダー）から未整理へ遷移できる
- [ ] 他人の素材が出ない

**手動QA**
- [ ] Usage削除（またはSession/Scene削除）により Usage=0 になったAssetが未整理に表示される
