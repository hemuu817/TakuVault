# Usage.role拡張 + 用途表示順固定化

## 目的

Usage.role に `standing`, `panel`, `sound_effect` を追加し、Session詳細「セッション素材一覧」の用途列を ADR-0016 に従った固定順で表示できるようにする。

既存Usageとの互換性を保ったまま、背景・立ち絵・カットイン・装飾パネル・BGM・効果音・その他を用途として扱える状態にする。

## 背景

ADR-0016では、Session詳細「セッション素材一覧」の用途列を Usage.role から生成しつつ、UI上の表示順は enum 定義順に依存しない方針としている。

Usage.role の enum 値は後方互換のため末尾追加を基本とする一方、UI上の自然な表示順は `background → standing → cutin → panel → bgm → sound_effect → other` とする必要がある。

そのため、本Issueでは role の追加と、用途表示順の正本となる `Usage::DISPLAY_ROLE_ORDER` の導入を扱う。

## スコープ

### 含む

* Usage.role に以下を末尾追加する

  * `standing`
  * `panel`
  * `sound_effect`
* 既存roleの整数値を変更しない

  * `background`
  * `cutin`
  * `bgm`
  * `other`
* enum定義順とUI表示順を分離する
* `app/models/usage.rb` に `Usage::DISPLAY_ROLE_ORDER` を定義する
* `Usage::DISPLAY_ROLE_ORDER` を以下の順序にする

  * `background`
  * `standing`
  * `cutin`
  * `panel`
  * `bgm`
  * `sound_effect`
  * `other`
* Usage.role の許容値と `Usage::DISPLAY_ROLE_ORDER` のキーが完全一致することを検証する
* Session詳細「セッション素材一覧」の用途列を `Usage::DISPLAY_ROLE_ORDER` 順に表示する
* 用途列をビュー側に固定配列でベタ書きしない
* 既存のUsage作成導線で追加roleを選択できるようにする

  * Primary：未整理（Usage0）ページで複数選択 → 一括割当
  * Secondary：Asset詳細Where usedで追加
* 追加roleで作成したUsageが以下に表示されることを確認する

  * Session詳細「セッション素材一覧」
  * Asset詳細Where used
* 追加roleの表示が既存roleと同じ表示方式で扱われることを確認する

  * 例：translation missing が出ない
  * 例：既存が日本語ラベル表示なら、追加roleも同じ方式で表示する
* role列増加後も、Session詳細で全用途列を参照できることを確認する

  * 横スクロール等による対応は許容する
  * 本Issueでは大規模なレスポンシブ再設計は行わない

### 含まない

* Asset.kind の実装
* Asset.kind から Usage.role を自動決定する処理
* kind-role 不一致をサーバ側で拒否する制約
* Asset.kind に基づく role 候補の自動絞り込み
* 未整理（Usage0）ページでの kind 連動UI補助
* Usage作成導線の大規模なUI変更
* Session詳細の大規模なレイアウト変更
* 横スクロール以外のレスポンシブ再設計
* Session詳細のドラッグ&ドロップ並び替え
* Usage.position の追加
* role管理画面
* 検索・絞り込み・タグ機能
