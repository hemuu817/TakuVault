## Body

## 目的（このIssueで達成する価値）
Cocofolia固定のSessionをCRUDでき、作成直後からWhere used前提のdefault_scene（position=1）が常に存在する状態を保証する。

## スコープ
**含む**
- Session CRUD（Cocofolia固定）
- room_url の保存・表示（http/httpsのみ許可）
- Session作成時に default_scene（position=1）を transaction で自動生成
- 認可（policy_scope/authorize）前提のCRUD

**含まない**
- 複数ツール対応（tool_variant等）
- room_url host allowlist（MVP不採用）
- Cocofolia API同期/連携

## 受け入れ条件（Yes/No）
- [ ] ログインユーザーは自分のSessionのみ閲覧/編集/削除できる（URL直打ちでも不可）
- [ ] room_url は http/https 以外（javascript:, data:, ftp:等）を保存できない
- [ ] Session作成成功時、default_scene（position=1）が必ず作成される（失敗ならSession作成も失敗）
- [ ] room_urlリンク表示は `target="_blank"` + `rel="noopener noreferrer"` が必ず付与される

## DoD（完了条件）
- [ ] policy_scope/authorize の適用漏れがない（index/show/new/create/edit/update/destroy）
- [ ] Session作成 transaction 内で default_scene を生成している
- [ ] room_url バリデーション（http/httpsのみ）がサーバ側で機能する
- [ ] 最小テスト/検証が通る（下記）

## 失敗ケース（最低3つ）
- [ ] room_url に `javascript:alert(1)` 等を入れて保存しようとして弾かれる
- [ ] Session作成は成功したが default_scene が作成されていない（＝許容しない）
- [ ] 他人のSession IDを指定して show/update/destroy できてしまう（＝許容しない）

## 最小テスト/検証
**Model/DB**
- [ ] room_url：http/httpsのみ許可（不正スキームは invalid）

**Policy**
- [ ] Session：index/show/create/update/destroy で所有権が効く

**System**
- [ ] Session作成 → default_scene（position=1）生成を確認
- [ ] room_url 不正スキームは作成できない
- [ ] 他人SessionへのURL直打ちは 404/403
