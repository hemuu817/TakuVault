# 素材一覧のRole / Tagスイッチ絞り込み

## 目的

独立した素材一覧 `Assets#index` に、UsageのRoleとTagによる複数選択の絞り込みを追加する。検索 `q` と組み合わせ、URLから選択状態と結果を再現できるようにする。

設計契約は専用ADRを正本とし、本IssueではUI・検索処理・状態維持・検証を実装する。

## 実装タスク

- [ ] Role / Tag絞り込みADRの正式な参照先を一本化し、未確定事項を解消してAcceptedにする
- [ ] Issue #29のRole絞り込み、#32のTag絞り込みを本Issueへ移管し、各Issueの範囲・依存関係を更新する
- [ ] Role / Tagスイッチ、追加Tagの展開UI、検索条件エラーからの復帰導線を実装する
- [ ] 認可済みAssetを対象に、入力検証・条件合成・重複排除を実装する
- [ ] GET queryによる状態維持と検索 `q` との連携を実装する
- [ ] ADR-0020の責務分担に従って自動テストと手動確認を行う

対象は `Assets#index` のみ。Session / Scene画面へのUI追加、`kind / session_id / scene_id` による絞り込み、Scene遅延ロード、Where usedとの表示同期、Tagの付与・管理操作、並び替えカスタマイズ、プリセット、検索・ソート・pagination自体の新規導入は含めない。

## 受け入れ条件

### 絞り込み結果

- [ ] Roleの初期状態は全選択で、UsageがないAssetも対象になる
- [ ] 一部Roleの選択では、選択Roleのいずれかを持つ認可済みUsageが存在するAssetだけが対象になる
- [ ] Role全解除は正常な0件となり、Usageなしを `other` として扱わない
- [ ] Tag未選択ではTag条件を適用せず、複数選択では選択Tagをすべて持つAssetだけが対象になる
- [ ] 検索 `q`・Role条件・Tag条件をANDで組み合わせられる
- [ ] 複数のUsage / AssetTagに一致しても、同じAssetを重複表示しない

### UI・URL

- [ ] 同じ絞り込み領域に、現在の7種類のRoleと登録順の先頭7件までのTagを表示する
- [ ] 8件目以降のTagも展開UIで選択でき、閉じた状態でも追加Tagの選択有無が分かる
- [ ] Role / Tagの選択状態が判別でき、Tagは最大15件まで選択・解除できる
- [ ] `q`・Role・Tagのいずれかを変更しても他の有効な条件を維持する
- [ ] URLで初期状態とRole全解除を区別でき、再読込後も選択状態と結果が一致する
- [ ] paginationがある場合、条件変更で1ページ目へ戻り、ページ移動時は絞り込み条件を維持する

### 入力検証・認可

- [ ] Asset結果・Tag候補・Role判定用Usageが、現在Userの認可範囲に限定される
- [ ] Tag IDの形式・構造・重複・件数とRole値を、Accepted済みADRの契約に従ってサーバー側で検証する
- [ ] 重複排除後のTagが15件を超える場合、または取得不能Tagが1件でも含まれる場合は422となる
- [ ] Role全解除時もTag検証を省略せず、不正・取得不能な値を黙って除外して検索しない
- [ ] 422ではAsset検索を実行せず、結果領域を空にして通常の0件とは異なるエラーを表示する
- [ ] 存在しないTag・削除済みTag・他User所有Tagについて、存在や所有者を判別できる応答を返さない
- [ ] Tag指定エラーから、利用者の明示操作でTag条件を解除し、有効な `q` とRoleを維持して再検索できる

- [ ] Request：Tagの15件・16件境界、重複・不正形式・取得不能・有効無効混在、未知のRole値、Role全解除と不正Tagの同時指定を検証する
