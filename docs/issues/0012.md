# #12 所有権の強制（URL直打ち・改ざんでも混入ゼロ）

## 目的
ユーザーごとにデータが完全に分離され、他人のレコードを閲覧/操作できない（所有権認可）状態を主要リソースの全CRUDで保証する。

## スコープ
**含む**
- Pundit Policy/Scope による所有権強制（#11の運用ルール前提）
- index は必ず `policy_scope` 起点（他人混入ゼロ）
- show/update/destroy は他人ID直打ちを 404 に寄せる（#11方針）
- create で他人外部キー混在を拒否（Usage/AssetTag含む）

**含まない**
- 管理者/共有/招待
- 権限ロール階層
- DB設計の追加変更（Epic C/D/F の制約で担保）

## 受け入れ条件（Yes/No）
- [ ] index で他人レコードが混入しない（常に policy_scope 起点）
- [ ] show/update/destroy の他人ID直打ちは 404
- [ ] create で他人の外部キー混在（Usage/AssetTag）が成立しない
- [ ] DB例外（FK違反等）をユーザーに見せない（404/422に収束）

## DoD
- [ ] Session/Asset/Tag は Scope が current_user 所有のみを返す
- [ ] Scene/Usage は「正本（Session/Asset）経由」で所有判定する（ADR参照）
- [ ] Usage/AssetTag の混在禁止を単一箇所に集約して実装する（ADR参照）
- [ ] 最小テスト（所有者OK/他人NG、混在NG）がCIで安定して通る

## 最小テスト/検証（CI安定重視）
- [ ] 他人レコード show 直打ち → 404（Session/Asset/Tag 代表）
- [ ] index に他人が混入しない（Session/Asset 代表）
- [ ] Usage 作成で混在パラメータ → 失敗（404/422に収束、500にしない）
- [ ] AssetTag 付与で他人 tag 指定 → 失敗（404/422に収束）

- Relates to: Epic C/D/F（Scene/Usage/Tag の整合）
- Relates to: ADR-0005（所有権の正本と混在禁止の定義）
