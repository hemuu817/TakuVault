# Sub-Issue: Demo用 seed & 初期データ（手動QA/デモ専用・改訂）

## 目的
- 手動QAとデモを**同一状態に再現**できる最小データを用意する（※CI判定はseedに依存させない）

## DoD
- [ ] `db/seeds/demo.rb` に分離（`db/seeds.rb` は最小/空）
- [ ] `db:seed:demo` の実行手段を固定（Rakeタスク等）
- [ ] **実行ガード**：development / staging のみ実行可（productionは即abort）
- [ ] **再現性**：実行後のデータが常に同一状態になる（方式固定：demoユーザー配下リセット→再生成）
- [ ] P0制約（default_scene必須、UsageのUNIQUE、添付必須、所有権）に適合
- [ ] サンプル添付が制限（Content-Type/拡張子/サイズ）に通る（小容量・権利クリア）

## スコープ
### 含む
- `db/seeds/demo.rb` / `lib/tasks/demo_seed.rake`
- `db/seed_files/`（小さいサンプルのみ、権利クリア素材）
- デモシナリオ固定（最小）
  - Demoユーザー 1
  - Session 1（room_urlあり）
  - Scenes：default + 1
  - Assets：画像2 + 音声1（添付あり）
  - Usages：role を最低1種類以上含め、Where used が説明できる

### 含まない
- CIの判定をseedに依存させる
- 大量データ/負荷目的
- 本番での自動seed投入

## 受け入れ条件（Yes/No）
- [ ] `bin/rails db:seed:demo` を実行すると、デモデータが投入される
- [ ] 2回実行しても件数が増えず、**同一状態に収束**する（demo配下リセット方式）
- [ ] デモユーザーでログインし、以下が確認できる
  - [ ] Asset一覧に素材がある／詳細で添付を参照できる
  - [ ] Where used（Asset→Usage）が表示できる（Session/Scene/Roleが見える）
- [ ] production環境では実行できない（abortされる）

## 依存 / 関連
- Depends on：EpicC（Session/Scene・default_scene）、EpicD（Asset/Usage・制約/添付）
- Related：Issue #42（手動QAの前提データとして利用。CI判定はspec側）

## 実装メモ（方式固定）
- 実行ガード：`Rails.env.production?` なら即 abort（必要なら `ALLOW_DEMO_SEED=true` で例外許可も可）
- 再現性：demoユーザー配下のみ安全に削除して再作成（他ユーザー/本番データは触らない）
- 添付：`db/seed_files/` の**小容量**・**権利クリア**素材のみ使用（制限変更時は更新対象）

## 手動QA（seed実行後）
- [ ] ログイン → Asset一覧 → Asset詳細（添付表示）
- [ ] Asset詳細 → Where used 表示（Session/Scene/Role確認）
