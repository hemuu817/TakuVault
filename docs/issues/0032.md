## Body

- DB設計は多対多（`tags` + `asset_tags`）
- MVPのUIは単数タグ選択でもOK
- タグで絞り込みできる
- 認可：Tagも user-owned（他人のタグは見えない/使えない）
- DB制約
  - `tags`：`UNIQUE(user_id, name)`
  - `asset_tags`：`UNIQUE(asset_id, tag_id)`
- 削除整合性（方針を固定）
  - Tag削除 → 中間（asset_tags）は削除（推奨：DBでON DELETE CASCADE）
  - Assetsは削除しない
