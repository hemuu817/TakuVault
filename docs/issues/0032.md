# Issue #32: (24) タグ付け（Tag + AssetTag）

- URL: https://github.com/hemuu817/TakuVault/issues/32
- State: OPEN
- UpdatedAt: 2026-08-10T07:26:43Z
- Labels: 

## Body

## 目的

素材（Asset）にTagを追加・解除でき、素材一覧とAsset詳細で付与済みTagを確認できる状態を作る。

また、素材一覧で複数Assetを選択し、1つのTagを一括付与できるようにする。

Tagによる検索・絞り込みは別Issueで扱う。

## Prerequisite

- ADR-0018がAcceptedになってから実装へ着手する
- Tag / AssetTagのドメインモデル、正規化、一意性、所有権整合性、付与上限、単体・一括付与、競合およびライフサイクルはADR-0018を正本とする

## Scope

### 含む

#### データモデル

- Tagモデルとtagsテーブル
- AssetTagモデルとasset_tagsテーブル
- User / Asset / Tag / AssetTag間のassociation
- ADR-0018で定義された一意性、所有者一致、外部キーおよび削除整合性
- DB制約とモデルvalidationの整合

#### 単体付与・解除

- Asset詳細からTagを追加できる
- 入力されたTagが既存の場合は再利用する
- 入力されたTagが存在しない場合は新規作成する
- Asset詳細からAssetTagを解除できる
- 単体付与の重複・上限到達結果を画面に表示する

#### 一括付与

- 素材一覧で複数Assetを選択できる
- 選択した複数Assetへ1つのTagを一括付与できる
- 既存Tagまたは新規Tagを一括付与に使用できる
- 一括付与の成功件数とスキップ結果を表示する
- スキップされたAssetと理由を確認できる
- ADR-0018で定義された対象件数上限、部分成功、fail-closedおよびトランザクション契約を適用する

#### Tag候補

- 認証済みUserが所有する既存Tagを候補として表示する
- 他Userが所有するTagを候補へ含めない
- 既存Tagの選択と、新しいTag名の入力を同じ付与導線で利用できる

#### 表示

- Asset詳細では付与済みTagを全件表示する
- Asset詳細で表示するTagは最大15件とする
- 素材一覧では各AssetのTagを最大3件まで表示する
- 素材一覧で4件以上のTagがある場合は、超過件数を`+N`で表示する
- 未整理（Usage0）ビューでも、各AssetのTagを最大3件と`+N`で表示する
- 表示順はADR-0018に従う

#### 認可・整合性

- 自分が所有するAssetにのみTagを追加・解除できる
- 自分が所有するTagのみ既存Tagとして指定できる
- 他Userまたは取得不能なAsset / Tagを含む操作をfail-closedで拒否する
- 一括付与では、全対象の認可が完了する前に書き込みを開始しない
- ADR-0018に従い、競合時にもTagの一意性と1 Assetあたり15 Tagの上限を維持する
- 予期しない失敗時に部分書き込みを残さない

#### 性能

- Asset詳細、素材一覧、未整理ビューおよび一括付与結果でN+1を発生させない

### 含まない

- TagによるAssetの検索・絞り込み
- Tag一覧画面・Tag管理画面
- Tagの改名
- Tagの統合
- Tagの手動削除UI
- 複数Tagの同時付与
- Tagの一括解除
- Assetに付与されたTagの全置換
- Tagの色・説明文
- ドラッグ&ドロップによるTagの並び替え
- 未整理（Usage0）ビューからの一括タグ付与
- User削除時の全所有リソースの削除処理

未整理（Usage0）ビューでのTag表示は本Issueに含むが、未整理ビューを起点とした一括付与は含まない。

## Acceptance Criteria

### Tagの同一性

- [ ] Tag名がADR-0018に従って正規化される
- [ ] 同一User内で同一と判定されるTagが重複作成されない
- [ ] 表記違いで同一と判定された場合は既存Tagが再利用される
- [ ] 既存Tagの再利用によって保存済み表示名が上書きされない
- [ ] 別User間では同じTag名を持てる
- [ ] 空のTag名を登録できない
- [ ] ADR-0018の文字数上限を超えるTag名を登録できない

### 単体付与・解除

- [ ] Asset詳細で既存Tagを追加できる
- [ ] Asset詳細で新規Tagを作成して追加できる
- [ ] 付与済みTagを単体付与した場合は422相当で拒否され、理由が表示される
- [ ] 16件目のTagを単体付与した場合は422相当で拒否され、理由が表示される
- [ ] Asset詳細で付与済みTagを解除できる
- [ ] AssetTagを解除してもTag自体は削除されない

### 一括付与

- [ ] 素材一覧で複数Assetへ1つのTagを一括付与できる
- [ ] 重複して指定されたAsset IDはユニークなAssetとして1回だけ処理される
- [ ] ADR-0018の対象件数上限を超える一括付与は422相当で全体が拒否される
- [ ] 付与済みTagを持つAssetは重複としてスキップされる
- [ ] 15 Tagに到達済みのAssetは上限到達としてスキップされる
- [ ] 付与可能なAssetにはTagが付与される
- [ ] 重複または上限到達によって一括付与全体が失敗しない
- [ ] 付与成功件数、重複スキップ件数、上限スキップ件数を確認できる
- [ ] スキップされたAssetと理由を確認できる
- [ ] 全Assetがスキップされた場合も、200相当の正常な「付与0件」として扱われる
- [ ] 付与可能Assetが0件の場合、不要な新規Tagが残らない

### 認可・fail-closed

- [ ] 他UserのAssetへTagを追加・解除できない
- [ ] 他UserのTagを既存Tagとして指定できない
- [ ] 一括付与に他Userまたは取得不能なAsset / Tagが含まれる場合、処理全体が拒否される
- [ ] 認可失敗時に一部のAssetTagまたは新規Tagが作成されない
- [ ] エラー表示から取得不能なIDや所有者情報が漏えいしない
- [ ] DBレベルでも異なるUserが所有するAssetとTagを関連付けできない

### 表示

- [ ] Asset詳細で付与済みTagが全件表示される
- [ ] Asset詳細では最大15件のTagが表示される
- [ ] 素材一覧で各AssetのTagが最大3件まで表示される
- [ ] 素材一覧で4件以上のTagがある場合、超過件数が`+N`で表示される
- [ ] 未整理ビューでもTagが最大3件と`+N`で表示される
- [ ] Tagの表示順がADR-0018の契約と一致する
- [ ] AssetTagを解除後に再付与したTagが末尾へ移動する

### 競合・トランザクション

- [ ] 同一Userが同一と判定されるTagを同時作成しても、最終的に1件へ収束する
- [ ] 同一Assetへの同時付与でも15 Tagを超えない
- [ ] 単体付与と一括付与が競合しても15 Tagを超えない
- [ ] 予期しないDBエラー時に当該操作の部分書き込みが残らない

### 削除整合性

- [ ] Asset削除時に関連AssetTagが残らない
- [ ] Tag削除時に関連AssetTagが残らない
- [ ] AssetTag削除時にAssetとTagは削除されない
- [ ] AssetTagが0件になったTagも自動削除されない
