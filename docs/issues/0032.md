## Body

# #32 (24) タグ付け（Tag + AssetTag）と一括付与 ※絞り込み無し／表示あり

## 目的（このIssueで達成する価値）

素材（Asset）にTagを追加・解除でき、Asset詳細と素材一覧で付与済みTagを確認できる状態を作る。

また、素材一覧で複数Assetを選択し、1つのTagを一括付与できるようにする。

Tagによる検索・絞り込みは別Issueで扱う。

## スコープ

**含む**

- データモデル
  - Tag / AssetTagのmigration、model、association
  - Tag / AssetTagのドメインモデル、正規化、一意性、所有権整合性、付与上限、競合およびライフサイクルはADR-0003に従う
  - DB制約とモデルvalidationを整合させる
- 単体付与・解除
  - Asset詳細からTagを追加できる
  - 入力されたTagが既存の場合は再利用する
  - 入力されたTagが存在しない場合は新規作成する
  - Asset詳細から付与済みTagを解除できる
  - 単体付与の重複・上限到達結果を画面に表示する
- 一括付与
  - 素材一覧で複数Assetを選択できる
  - 選択した複数Assetへ1つのTagを一括付与できる
  - 既存Tagまたは新規Tagを一括付与に使用できる
  - 入力Asset IDはユニークなAsset単位で処理する
  - 対象件数、部分成功、全件スキップ、fail-closedおよびトランザクションはADR-0003に従う
  - 付与成功件数、スキップ件数、スキップされたAssetと理由を表示する
- 既存Tag候補
  - 認証済みUserが所有する既存Tagを候補として表示する
  - 他Userが所有するTagを候補へ含めない
- 表示
  - Asset詳細では付与済みTagを全件表示する
  - 素材一覧では各AssetのTagを最大3件まで表示する
  - 素材一覧で4件以上のTagがある場合は、超過件数を`+N`で表示する
  - 未整理（Usage0）ビューでもTagを最大3件と`+N`で表示する
  - Tagの表示順はADR-0003に従う
- 認可・整合性
  - 自分が所有するAssetにのみTagを追加・解除できる
  - 自分が所有するTagのみ既存Tagとして指定できる
  - 他Userまたは取得不能なAsset / Tagを含む操作をfail-closedで拒否する
  - 一括付与では、全対象の認可完了前に書き込みを開始しない
  - 競合時にもADR-0003の一意性、15件上限および原子性を維持する
- 性能
  - Asset詳細、素材一覧、未整理ビューおよび一括付与結果でN+1を発生させない

**含まない**

- TagによるAssetの検索・絞り込み
- Tag一覧画面・Tag管理画面
- Tagの改名・統合・手動削除UI
- 複数Tagの同時付与
- Tagの一括解除
- Assetに付与されたTagの全置換
- Tagの色・説明文
- ドラッグ&ドロップによるTagの並び替え
- 未整理（Usage0）ビューからの一括タグ付与

未整理（Usage0）ビューでのTag表示は本Issueに含むが、未整理ビューを起点とした一括付与は含まない。
