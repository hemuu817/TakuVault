# #32 (21) タグ付け（Tag + AssetTag）※絞り込み無し／表示あり

## 目的（このIssueで達成する価値）
素材（Asset）にタグを付与でき、素材一覧/詳細でタグが視認できる状態を作る（検索・絞り込みは別Issue）。

## スコープ
**含む**
- データモデル
  - Tag（tags）
    - 所有者：user
    - 制約：UNIQUE(user_id, name)、name NOT NULL
  - AssetTag（asset_tags）
    - asset_id, tag_id の中間テーブル
    - 制約：UNIQUE(asset_id, tag_id)
    - FK：asset_tags.asset_id / asset_tags.tag_id に FK + ON DELETE CASCADE（推奨：DB寄せ）
- タグ名の正規化と一意性（MVP固定）
  - name は strip + squish（前後空白除去・連続空白除去）
  - 大文字小文字は区別する（case-sensitive）
- 付与/削除（MVP最小UI）
  - Asset詳細でタグの追加/削除ができる
  - 追加は「入力して追加（存在すれば再利用、なければ作成）」の単一導線でよい
  - 同一タグの二重付与は無害化（UNIQUEで防止、UIは冪等）
- 表示（重要：ここが本Issueの主旨）
  - Asset詳細で付与済みタグが表示される
  - **素材一覧（統合画面/未整理ビュー等）でもタグを表示する**
    - 表示は最大3件まで、超過分は「+N」省略可（MVPの表示崩れ防止）
- 認可（固定）
  - 入口は Asset 配下に固定し、タグ操作前に authorize(asset) を必須とする
  - tag の探索/作成は current_user.tags に限定する（他ユーザーtag_id混入をfail-closed）
  - 付与前に tag.user_id == asset.user_id を検証する（不一致は 404 または 403。全体方針に合わせて固定）
- 競合（レース）対策（MVP必須）
  - 同名タグ作成は create_or_find_by!（または RecordNotUnique rescue）で収束させる

**含まない**
- タグによる検索/絞り込み（スイッチUI等）（別Issue）
- タグ一覧画面/タグ管理画面（MVP外）
- 一括タグ付け、タグの並び替え/色/説明文

- [ ] Asset詳細でタグを追加できる（存在すれば再利用、なければ作成）
- [ ] Asset詳細でタグを削除できる
- [ ] 素材一覧でタグが表示される（上限3件、超過は「+N」でも可）

- [ ] 他ユーザーのtag_idを指定して自分のAssetに紐付けできてしまう（認可漏れ）
- [ ] 同名タグが同一ユーザー内で増殖する（正規化/一意制約/競合吸収不足）
- [ ] 同じタグを同一Assetに複数回付けられる（中間一意制約不足）
