# #10 Devise登録・ログイン（Rails 7 / Turbo前提）

## 目的
ユーザー登録・ログイン・ログアウトが Turbo 有効のまま安定動作し、未ログインでは保護ページへ入れない状態を作る。

## スコープ（含む）
- Devise導入（User生成、migrate、structure.sql反映）
- サインアップ/サインイン/サインアウトのUI動作
- Turbo互換の安定化（422/303）
- ログアウトDELETEの保証（button_to か data-turbo-method）
- authenticate_user! の適用方針固定

## スコープ（含まない）
- 認可（Pundit / policy_scope / authorize）
- 所有権（user_idでCRUD隔離）
- confirmable/2FA等

## 受け入れ条件（Yes/No）
- [x] サインアップできる
- [x] サインインできる（成功後に遷移が破綻しない）
- [x] サインアウトできる（DELETEで成立）
- [x] 未ログインで保護ページ直打ち → サインインへ誘導される
- [x] ログイン失敗時にエラー表示される（Turboでも画面が壊れない）
  - ※入力パターンの網羅は system spec で担保する

## DoD
- [x] Devise responder status を固定（422/303）
- [x] ログアウト方式を固定（DELETE保証）
- [x] `db/structure.sql` が最新
- [x] System spec（成功系 + 失敗代表2〜3ケース）がCIで安定して通る

## 最小テスト/検証（System）
- [x] サインアップ→ログイン状態→ログアウト
- [x] 未ログイン直打ちで誘導
- [x] ログイン失敗（例：空白 or 誤り）でエラー表示（Turboでも崩れない）
