## Body

##36 Session詳細：セッション素材一覧表示

## 目的（このIssueで達成する価値）
Session詳細で、そのセッション内の各Sceneに紐づく素材（Asset）を、Scene × 用途（role）単位で俯瞰できるようにする。

#22 Asset詳細Where used は「Asset起点で使用先を確認する」Issueである。
本Issueは「Session/Scene起点で、そのセッション内で使われている素材を確認する」Issueとして分離する。

## スコープ

**含む**
- Session詳細ページに「セッション素材一覧」セクションを追加する
- 行=Scene、列=用途（= role enum の表示名）として、当該Session内の usages をグリッド表示する
- Scene は position 昇順で表示する
- default_scene は position=1 として先頭に表示する
- 用途列は role enum の定義順で表示する
- セル（scene × role）には、該当Usageに紐づくAssetをタイル表示する
- Assetタイルの表示項目：
  - サムネイル
  - display_name
- タイルクリックで Asset詳細へ遷移できる
- 音声Assetは固定サムネイルで表示する
- セッション素材一覧内では音声を再生しない
- セル内のAsset表示順を安定化する
  - usages.created_at 昇順
  - 同一created_atの場合は usages.id 昇順
- Usageが存在しないScene / 用途でも、画面が壊れない表示にする
- 認可：Sessionを authorize し、表示対象Scene / Usage / Asset は current_user 所有範囲に限定する（fail-closed）
- N+1回避：Session詳細で必要な scenes / usages / assets / ActiveStorage attachment を eager load する（includes/preload 等）

**含まない**
- Usage の作成・編集・削除（本Issueは表示のみ）
- Asset の作成・編集・削除
- Session / Scene の作成・編集・削除
- 未整理素材一覧の実装
- 検索・絞り込みUI
- 横断ツリー表示
- 遅延ロード
- グリッド内での音声再生
- Session詳細専用のモーダル詳細表示
- 素材詳細ページと別内容の詳細UI
- DB変更
- migration追加
- 新規制約追加
