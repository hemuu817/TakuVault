## Body

- Where usedの価値が明確（素材→どのセッション/シーン/役割で使ったかを逆引き）
- Cocofoliaのみ、room_url参照保存で同期しない旨が明確
- MVP/本リリース/将来検討の区分が明確
- MVPで提供するアップロードが「一括アップロード（ドラッグ&ドロップ + 複数選択フォールバック）」である旨が明記されている
- tag と kind（素材種別）の違いが明記されている
  - kindは素材種別（画像/音声等）
  - tagは分類ラベル（DBは多対多。MVP UIは単数でも可）
- Where used成立条件の最低ラインが明記されている
  - 未分類Scene（default_scene）が常に存在し削除できない
  - Usageは必ずSceneに紐付く（scene_id NOT NULL）
  - 同一 asset + session + scene + role の重複登録は不可
- room_urlの安全性が明記されている
  - 許可スキームは http/https のみに限定
  - リンクは `target="_blank"` + `rel="noopener noreferrer"` 等で安全に遷移
  - host allowlistはMVPでは不採用（揺れが大きく運用が詰みやすい）である旨が明確
- Asset削除時にUsageも削除される方針が明記されている
- Session/Scene/Tagの削除整合性の方針が明記されている（指示文と一致）
- 容量/Content-Type制限など運用制約がREADMEに明記されている
