# Usage.role絞り込み + 表示順並び替え

## 目的（このIssueで達成する価値）
ADR-0016に従い、Usage.role に `standing`, `panel`, `sound_effect` を追加し、Session詳細「セッション素材一覧」の用途列を自然な固定順で表示できる状態にする。

既存Usageとの互換性を保ったまま、背景・立ち絵・カットイン・装飾パネル・BGM・効果音・その他を用途として扱えるようにする。

## スコープ
**含む**
- Usage.role に以下を末尾追加する
  - `standing`
  - `panel`
  - `sound_effect`
- 既存roleの整数値を変更しない
- enum定義順とUI表示順は一致しなくてよい
- `Usage::DISPLAY_ROLE_ORDER` を定義する
- 用途の固定表示順を以下にする
  - `background`
  - `standing`
  - `cutin`
  - `panel`
  - `bgm`
  - `sound_effect`
  - `other`
- Usage.role の許容値と `Usage::DISPLAY_ROLE_ORDER` の整合を検証する
- Session詳細「セッション素材一覧」の用途列が `Usage::DISPLAY_ROLE_ORDER` 順に表示されるようにする
- 既存のUsage作成導線が追加roleに対応していることを確認する
- Asset詳細Where usedで追加roleのUsageが表示されることを確認する
- role列増加後も、Session詳細が破綻しないことを最低限確認する

**含まない**
- Asset.kind の実装
- Asset.kind から Usage.role を自動決定する処理
- kind-role 不一致をサーバ側で拒否する制約
- 未整理（Usage0）ページでの kind 連動UI補助
- kind別のrole候補絞り込み
- Usage作成導線の大規模なUI変更
- Session詳細の大規模なレイアウト変更
- 横スクロール以外のレスポンシブ再設計
- Session詳細のドラッグ&ドロップ並び替え
- Usage.position の追加
- role管理画面
- 検索・絞り込み・タグ機能
