# Issue #174: (45) セッション画面の統合

- URL: https://github.com/hemuu817/TakuVault/issues/174
- State: OPEN
- UpdatedAt: 2026-08-11T14:12:48Z
- Labels: 

## Body

## 目的（このIssueで達成する価値）

現在独立しているSession一覧とSession詳細を同一画面へ統合し、Session一覧へ戻ることなく、Sessionの切替・管理と、選択Sessionに属するScene・Usage・使用素材の確認を行えるようにする。

素材一覧はAssetを起点とする独立した主要画面として維持し、Session画面はSessionを起点とする主要画面として整理する。

画面構成、URL、Session切替時の状態遷移、CRUD後の表示状態、取得境界および認可境界はADR-0019を正本とする。

## スコープ

**含む**

- Session一覧とSession詳細の統合
  - 既存のSession一覧とSession詳細を一つのSession画面へ統合する
  - Session一覧・管理領域と、選択Sessionの詳細領域を同一画面に表示する
  - 基本レイアウトと狭い画面での責務はADR-0019に従う
  - `/sessions`をSession未選択状態の統合画面とする
  - `/sessions/:id`を対象Sessionが選択された統合画面とする
  - `/sessions/:id`への直接アクセスでも、Session一覧と選択Session詳細の両方を表示する
  - Sessionが存在していても、`/sessions`で先頭Sessionを自動選択しない
  - Sessionが0件の場合は、空状態とSession作成導線を表示する
- Session一覧・管理領域
  - Sessionを選択・切替できる
  - 選択中Sessionを判別できる
  - Sessionの作成・編集・削除へ移動できる
  - Sessionの選択操作と削除操作を明確に分離する
  - 特定のSession件数だけを前提とする画面構造に固定しない
- 選択Sessionの詳細領域
  - Session基本情報、Session名、room_urlを表示する
  - Session編集への導線を表示する
  - Scene一覧とScene作成・編集・削除への導線を表示する
  - 既存の「セッション素材一覧」を表示する
  - Assetタイルから既存のAsset詳細へ遷移できる
  - 選択Sessionの詳細表示を、Session一覧と組み合わせて利用できる表示責務へ分離する
- Session切替
  - URL、一覧上の選択表示、Session詳細をADR-0019に従って更新する
  - 切替中は直前の正常な表示状態を維持し、切替中であることを表示する
  - 切替成功時はURL、選択表示および詳細を対象Sessionへまとめて更新する
  - Session切替ごとのブラウザ履歴は追加しない
  - 切替失敗時は直前の正常な状態を維持し、エラーと再試行導線を表示する
  - 連続切替時は最後に選択したSessionの結果だけを反映する
  - リロードおよびTurboキャッシュ復元時はURLから状態を再構築する
- Scene・Usage・Assetの取得
  - Session一覧ではSession選択に必要な情報だけを取得する
  - 選択された一つのSessionについて、Scene・Usage・表示対象Assetをまとめて取得する
  - 全Session配下のScene・Usage・Assetを一括取得しない
  - Scene単位の遅延ロードは行わない
  - 既存の`Sessions::AssetGridQuery`と「セッション素材一覧」の表示責務を統合画面から利用できるようにする
  - 表示順はADR-0016に従う
  - default_sceneはADR-0001に従う
  - 所有権と認可境界はADR-0007に従う
  - Usage・Asset・Active Storage関連でN+1を発生させない
- Session CRUD後の状態
  - Session作成・編集結果をSession一覧とSession詳細の両方へ反映する
  - Session作成・編集後は対象Sessionを選択状態にする
  - 選択中Sessionの削除後はSession未選択状態にし、別Sessionを自動選択しない
  - 選択されていないSessionの削除後は、現在の選択状態を維持して削除対象だけを一覧から除去する
  - Session削除失敗時は現在の正常な状態を維持し、失敗を表示する
- Scene CRUD後の状態
  - Scene CRUD後も親Sessionの選択状態を維持する
  - Scene作成・編集結果をScene一覧と「セッション素材一覧」の両方へ反映する
  - Scene削除後は、削除したSceneとそのSceneに属するUsageを画面に残さない
  - Scene CRUD後は既存の表示順でScene一覧と「セッション素材一覧」を再構築する
- Turboキャッシュ
  - URLとSession一覧上の選択状態を一致させる
  - loading中または通信失敗中の一時状態を正常な状態として復元しない
  - 削除済みSessionまたは削除済みSceneを正常な状態として復元しない

**含まない**

- 素材一覧へのSession選択・管理領域の統合
- root routeの変更
- 新しいdashboard画面またはdashboard専用routeの作成
- 既存の「セッション素材一覧」の再設計
- Session / Scene CRUDフォームのインライン化またはモーダル化
- Scene詳細のインライン化またはモーダル化
- Asset詳細のインライン化またはモーダル化
- Session選択UIの最終形式
- Session一覧の検索・ページネーション・仮想表示
- 素材一覧の検索・絞り込み・タグ・ソート機能の変更
- 大量Scene向けのページネーション・仮想表示・遅延ロード
- Session配下のScene作成件数に対する新しいハード上限
- Session / Scene / Usage / Assetのデータモデル変更
- プラン別Session上限、課金および上限到達時の制御

## 最小テスト/検証

**Request**

- [ ] `/sessions`をSession未選択状態として表示できる
- [ ] Sessionが0件でも`/sessions`を正常に表示できる
- [ ] 自分が所有するSessionの`/sessions/:id`を表示できる
- [ ] `/sessions/:id`の応答にSession一覧と選択Session詳細が含まれる
- [ ] 存在しない、削除済み、または他ユーザーのSessionを404相当で拒否する
- [ ] 選択Sessionの認可境界を越えるScene・Usage・Assetを応答へ含めない
- [ ] Usageが0件の場合も正常な空状態を返す
- [ ] 同一Assetの複数Usageを重複排除しない
- [ ] Session作成・編集後に対象Sessionの`/sessions/:id`へ遷移する
- [ ] 選択中Sessionの削除後に`/sessions`へ遷移する
- [ ] Session削除失敗時に成功通知を出さず、対象Sessionの`/sessions/:id`へ戻す
- [ ] Scene CRUD後に親Sessionの`/sessions/:id`へ遷移する

**Policy**

- [ ] Session一覧と選択Sessionを認可済みSessionの範囲から取得する
- [ ] 他ユーザーのSession URL直打ちを404相当で拒否する
- [ ] 選択Sessionの境界を越えるScene・Usage・Assetを表示しない
- [ ] Session一覧上の編集・削除導線だけを権限判定の根拠にしない

**Query / 性能**

- [ ] Session一覧の表示で全Session配下のScene・Usage・Assetを取得しない
- [ ] 選択Sessionだけを詳細取得の対象とする
- [ ] Scene・用途・セル内Assetの表示順がADR-0016と一致する
- [ ] Usage・Asset・Active Storage関連の件数に比例してSQLクエリが増加しない

**System**

- [ ] Session未選択状態からSessionを選択できる
- [ ] Session切替中、成功時および失敗時の表示状態がADR-0019と一致する
- [ ] 連続切替時に最後に選択したSessionの結果だけが表示される
- [ ] Session切替ごとの履歴が追加されず、ブラウザバックで統合画面へ遷移する前の画面へ戻れる
- [ ] 切替失敗後に再試行できる
- [ ] リロードおよびTurboキャッシュ復元後にURLから正しい状態が再構築される
- [ ] 削除済みSessionまたは削除済みSceneがTurboキャッシュから復元されない
- [ ] Session作成・編集結果が一覧と詳細の両方へ反映される
- [ ] 選択中Sessionと選択されていないSessionの削除後状態がADR-0019と一致する
- [ ] Session削除失敗時に直前の正常状態が維持され、失敗が表示される
- [ ] Scene CRUD結果がScene一覧と「セッション素材一覧」の両方へ反映される
- [ ] AssetタイルからAsset詳細へ遷移できる
- [ ] room_urlリンクの安全属性が維持されている
- [ ] 他ユーザーのSession・Scene・Usage・Assetが表示されない

**手動確認**

- [ ] 通常幅でSession一覧・管理領域と選択Session詳細を確認できる
- [ ] 狭い画面でもSessionの選択・管理と選択Session詳細の確認ができる
- [ ] Session切替中と通信失敗時の状態を識別できる
- [ ] ブラウザバックがSession選択履歴ではなく、統合画面へ遷移する前の画面へ戻る
- [ ] 再試行後にURL・選択表示・詳細が同じSessionを示す
