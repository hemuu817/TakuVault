## 目的
Render（Docker）上に **単一の検証環境（preview）** を用意し、
「動作確認できる定義（ヘルスチェック・DB migrate・画面表示）」を固定する。
以降の機能実装はこの環境で検証可能にする。

※このIssueでは **永続ストレージ（R2）は導入しない**（後続Issueで対応）。
そのため、この時点では ActiveStorage 添付の永続性は保証しない（RenderのFSは揮発し得る）。

## 前提（用語の整理）
- Render上の環境は **単一（preview）** とし、**staging / production の2環境は作らない**
- ただし Railsの実行モードは **production相当設定** として `RAILS_ENV=production` を前提にする  
  （＝“環境の呼称”と“Railsの実行モード”を区別する）
