## Body

## 目的
素材をタグで分類できるようにし、一覧での絞り込み（タグボタン押下）と運用（整理）を成立させる。

## スコープ
### 含む
- Tag：作成/削除（ユーザー所有で隔離）
- Asset：タグ付与/解除（多対多）
- 一覧：タグで絞り込み（タグボタン押下で反映、解除できる）
- DB制約/整合性（ユニーク、参照整合性、削除整合性）

### 含まない
- タグ階層、色、オートコンプリートの作り込み
- 複数タグ同時絞り込み（MVP外）
- タグ名の更新（リネーム）（※MVPで不要ならここに固定。必要なら含むへ移動）

## DoD
- [ ] Tagを作成/削除できる（`policy_scope/authorize` で所有権隔離、URL直打ちも防ぐ）
- [ ] Assetにタグを付与/解除できる（多対多）
- [ ] DB制約（structure.sql前提）
  - [ ] tags は UNIQUE(user_id, name)
  - [ ] asset_tags は UNIQUE(asset_id, tag_id)
  - [ ] asset_tags.asset_id -> assets.id ON DELETE CASCADE
  - [ ] asset_tags.tag_id -> tags.id ON DELETE CASCADE
- [ ] タグ名の正規化が固定されている（最低限：trim、空文字禁止）
- [ ] 一覧でタグ絞り込みが機能する（タグボタン押下→反映、解除可）

## 受け入れ条件（Yes/No）
- [ ] タグを作成できる（同名は作れない。空白のみは不可）
- [ ] Assetにタグを付け外しできる（tag_id改ざんで他人タグを紐付けできない）
- [ ] タグ削除で中間テーブルが破綻しない（asset_tagsが残らない、Assetsは残る）
- [ ] タグボタン押下で一覧の絞り込みが反映される（解除もできる）

## 最小テスト/検証
- Model/DB
  - [ ] tags：UNIQUE(user_id, name)
  - [ ] asset_tags：UNIQUE(asset_id, tag_id)
- Policy
  - [ ] 他人Tagは参照/操作できない（index/show/destroy等）
  - [ ] tag_id改ざんで他人Tagを紐付けできない
- System
  - [ ] Assetにタグ付与→一覧でタグ絞り込みに反映（タグボタン押下）
