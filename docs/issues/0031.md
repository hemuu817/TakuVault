## Body

# 目的
素材をタグで分類できるようにし、**素材一覧でタグボタン（チップ）による単一タグ絞り込み**を成立させる。
※MVPでは「複数タグAND/OR」「タグ階層」「色」「オートコンプリート」は扱わない。

---

## DoD（Definition of Done）
- [ ] Tag を作成/一覧/削除できる（**所有権で隔離**）
- [ ] Asset にタグを付与/解除できる（多対多：asset_tags）
- [ ] **Assets一覧でタグチップを表示し、クリックで単一タグ絞り込みできる**
- [ ] tags は UNIQUE(user_id, name)（※正規化方針に従う）
- [ ] asset_tags は UNIQUE(asset_id, tag_id)
- [ ] 参照整合性：asset_tags は tags/assets に対して **FK** を持つ
- [ ] 削除整合性：
  - [ ] Tag削除時、asset_tags が整合する（中間テーブルは残らない / 破綻しない。Assetsは残す）
  - [ ] Asset削除時も asset_tags が整合する（中間テーブルは残らない）

---

## スコープ

### 含む
- Tag 管理（必要最小限）
  - 作成
  - 一覧表示
  - 削除
  - （Rename は MVP外）
- Asset 詳細でのタグ付与/解除（1件ずつ操作で可）
- Assets 一覧でのタグ絞り込み（単一タグ）
  - タグチップ表示
  - チップクリックで絞り込み（GETパラメータで可）
  - 絞り込み解除（クリア導線）
- DB制約
  - ユニーク制約（tags / asset_tags）
  - 外部キー（asset_tags → tags, assets）
  - 削除時整合性（DB CASCADE か AR dependent かを方式固定）

### 含まない
- 複数タグ AND/OR 絞り込み
- タグ階層
- タグの色
- オートコンプリート/検索UIの作り込み
- タグのrename（MVP外）

---

## 受け入れ条件（Yes/No）

### タグ管理
- [ ] タグを作成できる
- [ ] 同一ユーザー内で同名タグは作成できない（ユニーク制約で担保）
- [ ] 自分のタグのみ一覧・削除できる（他ユーザーのタグは見えない/操作できない）

### タグ付与/解除
- [ ] Asset 詳細でタグを付け外しできる
- [ ] 自分の Asset に対してのみタグ付与/解除できる（他人の Asset を指定しても操作できない）
- [ ] 自分の Tag のみ付与できる（他人の tag_id を指定しても付与できない）

### 絞り込み（単一タグ）
- [ ] Assets 一覧にタグチップが表示される（表示する範囲は「自分のタグ」に限定）
- [ ] タグチップを押すと、そのタグが付いた Asset のみが一覧に表示される
- [ ] 絞り込み状態が UI で判別でき、解除できる（例：クリアボタン、再クリック等）
- [ ] 削除済みタグの tag_id を指定しても 500 にならず、結果0件等で安全に表示できる

### 削除整合性
- [ ] Tag を削除しても asset_tags が破綻せず、参照整合性が保たれる（中間テーブルに孤児が残らない）
- [ ] Asset を削除しても asset_tags が破綻しない（中間テーブルに孤児が残らない）

---

## 実装メモ（方式固定・ブレ防止）
- 認可：Pundit等で **policy_scope/authorize を全CRUDで徹底**（Tag / AssetTag / Asset）
- 絞り込み：GETクエリパラメータ（例：`?tag_id=...`）で十分。MVPでは複雑なJSは不要。
- JOIN：一覧で JOIN を使う場合は `distinct` で重複排除する。
- DB整合性：削除整合性は **DB CASCADE か AR dependent かに寄せて矛盾させない**（推奨：DB CASCADE）

---

## 最小テスト / 検証
- [ ] Model/DB：tags UNIQUE(user_id, name) / asset_tags UNIQUE(asset_id, tag_id)
- [ ] Model/DB：asset_tags の FK（tags/assets）と削除整合性（CASCADE等）の担保
- [ ] Policy：Tag/Asset/AssetTag の所有権（他人のID直打ちで弾ける）
- [ ] System：
  - [ ] Asset詳細：タグ付与 → 表示に反映 → 解除 → 反映
  - [ ] Assets一覧：タグチップ表示 → クリックで絞り込み → 解除で戻る
  - [ ] Tag削除後：該当タグでの絞り込みアクセスでも 500 にならない
