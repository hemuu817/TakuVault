# #20 Asset.kind

## 目的（このIssueで達成する価値）
ADR-0002で固定した `assets.kind`（content_type自動判定）を実装し、一覧/未整理/検索で使える状態にする。

## スコープ
**含む**
- `assets.kind` の追加（enum/int、NOT NULL、default: other）
- 添付（has_one_attached :file）から kind を自動設定して保存
- リクエストで `kind` を送っても反映されない（改ざん不可）

**含まない**
- 手動編集UI（MVP外）
- 添付差し替え（MVP外）
- 許可/拒否（Content-Type/拡張子/サイズ上限）の仕様決定（別Issue）

## 受け入れ条件（Yes/No）
- [ ] Asset作成時、Blobの `content_type` に基づき kind が自動設定される（ADR-0002準拠）
- [ ] 添付なしではAssetを作成できない
- [ ] `assets.kind` は NOT NULL（default: other）で保存される
- [ ] `kind` パラメータを送っても値は上書きできない
- [ ] structure.sql に反映されている

## DoD（完了条件）
- [ ] migration追加（kind列、NOT NULL、default）
- [ ] 判定ロジックがモデル/サービスのどちらかに集約されている
- [ ] 最小テストが通る（下記）

## 失敗ケース（最低3つ）
- [ ] `kind` をparamsで改ざんできる
- [ ] `image/png` が other になる（判定漏れ）
- [ ] 添付なしで保存できてしまう（kind前提が崩れる）

## 最小テスト/検証
**Model/DB**
- [ ] 添付必須
- [ ] image/png→image、audio/mpeg→audio
- [ ] kind NOT NULL + default other

## 追加スコープ：未整理（Usage0）ページのkind連動補助

Asset.kind は、未整理（Usage0）ページの一括割当フォームで Usage.role 候補を絞り込むためにも利用する。

目的は、画像素材へ `bgm`、音声素材へ `background` のような誤割当を通常操作上で防ぐことである。

### 含む

* 未整理（Usage0）ページで、Asset.kind に応じて Usage.role 候補を絞り込む
* 最初に選択されたAssetのkindを基準に、同じkindのAssetのみ選択可能にする
* 異なるkindのAssetは薄く表示し、checkboxを disabled にする
* 選択中kindのAsset群を一覧上部に移動する
* 未選択時の基本表示順は `image > audio > other` とする
* Usage.role に `standing`, `panel`, `sound_effect` を末尾追加する
* Usage.role のUI表示順は `Usage::DISPLAY_ROLE_ORDER` に集約する

### 含まない

* Asset.kind から Usage.role を自動決定する処理
* kind-role 不一致をサーバ側で拒否する制約
* Asset一覧全体の検索・絞り込み・タグ機能
* 非同期リクエストによる未整理一覧の再取得
* ドラッグ&ドロップによる並び替え
* 添付差し替え時のkind再判定

### 受け入れ条件

* [ ] `assets.kind` がBlobのcontent_typeに基づいて自動設定される
* [ ] `kind` パラメータを送ってもAsset.kindを上書きできない
* [ ] Usage.role に `standing`, `panel`, `sound_effect` が末尾追加され、既存roleの整数値が変わっていない
* [ ] 未整理（Usage0）ページで、未選択時のAsset表示順が `image > audio > other` になる
* [ ] image Asset選択時、image Assetのみ選択可能になり、role候補が画像系に絞られる
* [ ] audio Asset選択時、audio Assetのみ選択可能になり、role候補が音声系に絞られる
* [ ] other Asset選択時、other Assetのみ選択可能になり、role候補が `other` のみになる
* [ ] 全選択解除時、表示・選択可否・role候補が初期状態に戻る
* [ ] kind-role 不一致をサーバ側で拒否していない
* [ ] Asset.kind から Usage.role を自動決定していない
