# #20 Asset.kind

## 目的（このIssueで達成する価値）
ADR-0017で固定した `assets.kind`（content_type自動判定）を実装し、一覧/未整理/検索等で利用できる分類軸として保存できる状態にする。

## スコープ
**含む**
- `assets.kind` の追加（enum/int、NOT NULL、default: other）
- Asset.kind の値は `other`, `image`, `audio` に固定する
- `video` は定義しない
- 添付（has_one_attached :file）から kind を自動設定して保存
- リクエストで `kind` を送っても反映されない（改ざん不可）
- 既存Assetがある場合、migration時に `kind` が NULL のまま残らないようにする

**含まない**
- 手動編集UI（対象外）
- 添付差し替え（対象外）
- 許可/拒否（Content-Type/拡張子/サイズ上限）の仕様決定（別Issue/ADR）
- Usage.role の追加
- `Usage::DISPLAY_ROLE_ORDER` の追加・更新
- 未整理（Usage0）ページでの kind 連動UI補助
- Asset.kind から Usage.role を自動決定する処理
- kind-role 不一致をサーバ側で拒否する制約
- Asset一覧全体の検索・絞り込み・タグ機能

## 受け入れ条件（Yes/No）
- [x] Asset作成時、Blobの `content_type` に基づき kind が自動設定される（ADR-0017準拠）
- [x] `image/png` または `image/jpeg` が `image` になる
- [x] `audio/mpeg` または `audio/wav` が `audio` になる
- [x] 判定対象外または不明な `content_type` は `other` になる
- [x] 添付なしではAssetを作成できない
- [x] `assets.kind` は NOT NULL（default: other）で保存される
- [x] Asset.kind の enum は `other: 0`, `image: 1`, `audio: 2` で定義されている
- [x] `video` が Asset.kind に定義されていない
- [x] `kind` パラメータを送っても値は上書きできない
- [x] 既存Assetがある場合、migration後に `kind` が NULL のAssetが残らない
- [x] structure.sql に反映されている
